# Матрица соответствия ТЗ v1

Статус — первый инженерный срез. «Частично» не означает прохождение полного
приёмочного теста T01–T26 из PDF. Локальные тесты не заменяют педагогические
оценки, устройства и пилот. Уточнение пользователя: тариф рассчитывается по
каждому ребёнку; начальная цена 10 000 ₸/месяц, доступна настройка в админке.

| Требование | Статус | Реализовано / следующий шаг |
| --- | --- | --- |
| FR01 Профиль | Частично | Семья, до 5 профилей, отдельные токены и ownership; нужны подтверждённый взрослый и чистый AI-контекст |
| FR02 Каталог | Частично | 2014 нормативных целей с происхождением и 32 черновика RU/KK; ребёнку только опубликованное своего класса/языка; нужен human review и полный охват |
| FR03 Урок | Частично | Браузер и Flutter: попытка, серверная подсказка, перенос, пауза, выход; нужны публикация reviewed-контента и устройства |
| FR04 Педагогика | Не оценено | Детерминированная подсказка; нужны корпус и review учителей |
| FR05 Проверка | Частично | Ограниченный арифметический AST без eval, проверка эталонов и вариантов, needs_clarification; нужны другие типы заданий |
| FR06 Адаптация | Не реализовано | Одна тема; нужны рекомендации по подтверждённым evidence |
| FR07 Языки | Частично | Основные Flutter-экраны ARB RU/KK/EN, контент RU/KK; нужны полная вычитка и локализация всех состояний |
| FR08 Фото | Не реализовано | Честная недоступность; нужны upload intents, OCR и подтверждение revision |
| FR09 Доска | Частично | Счётчики с текстовым эквивалентом; нужны JSON Schema и renderer-блоки |
| FR10 Прогресс | Частично | Evidence по цели/версии, отдельно самостоятельность и помощь, дедупликация, без заявления mastery; нужна педагогическая оценка |
| FR11 Голос | Не реализовано | Микрофон не захватывается; нужен adapter и policy gates |
| FR12 Перебивание | Не реализовано | Нужны голосовой транспорт и серверная отмена generation |
| FR13 Лимиты | Не реализовано | Настраиваемый лимит профилей не является квотой обучения |
| FR14 Gate | Частично | Серверный PIN, scrypt, child scope, idle/background lock, пароль для privacy; нужны подтверждение контакта и recovery |
| FR15 Согласия | Частично | Непредвыбранные цели, immutable events, отмена уроков; нужны юридические версии |
| FR16 Время | Частично | UTC timestamps, timezone семьи; нужны часы квот и расписание |
| FR17 Подписка | Частично | Расчёт по детям, однократная проба, админка цены/лимита/длительности, ревизии и audit; нужны магазины, refunds, entitlement |
| FR18 Данные | Частично | Scoped JSON export, deletion jobs, реаутентификация, токены отзываются сразу, отдельный локальный ledger и проверка restore; нужны production storage/SLA |
| FR19 Офлайн | Не реализовано | Офлайн-ответы не выдаются за сохранённые; нужны подписанные пакеты и очередь |
| FR20 CMS | Частично | A01–A03: роли, immutable payload versions, две проверки, независимый издатель, publish/retire/rollback и аудит; нужны реальные reviewers и релизный manifest |
| FR21 Child safety | Не реализовано | Нет свободного AI-чата; нужны policy, adversarial-набор и escalation |
| FR22 Injection | Частично | UI экранирует профильные строки; нужны проверки OCR/model outputs |
| FR23 Доступность | Частично | Semantic HTML, клавиатура, крупные кнопки, mobile; нужны AA audit, 200% и Flutter Semantics |
| FR24 Логи | Частично | Request bodies и credentials не логируются; нужен полный data inventory |
| FR25 Отказы | Частично | Error envelope и UI-ошибки; нужны timeout/backoff и provider outage tests |
| FR26 Расходы | Не реализовано | Калькулятор не usage ledger; нужны атомарные резервы и caps |

## Следующие этапы

1. Сверить все состояния Flutter и браузера с макетами, проверить устройства.
2. Пройти независимую методическую/языковую проверку подготовленных черновиков,
   расширить материалы на все требуемые предметы и применимые редакции программы.
3. Подтверждение контакта, recovery, юридические версии согласий, PostgreSQL,
   production auth/TLS, внешние encrypted backups, расписание и серверные квоты.
4. AI/OCR/голос: поставщики, допустимые потоки и хранение, ключи через настройки,
   отмена, квоты, ревизии, неопределённость и раздельные согласия.
5. Платёжный провайдер/магазины, подтверждённые entitlement по ребёнку,
   usage ledger, refund/restore. Расчёт стоимости не является оплатой.
6. Подписанный offline, полный T01–T26, пилот, доступность и релизные gates.

Цена, состав подписки и одна проба 3 дня на семью уточнены пользователем; скидки, дополнительные
тарифные планы и платёжный поставщик пока не определены. Они не подменяются
допущениями из примеров ТЗ.
