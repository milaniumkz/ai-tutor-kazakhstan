# AI Репетитор · Казахстан

Первый рабочий срез приложения по предоставленным ТЗ v1 и каталогу макетов.
Постоянная база, семейные профили, отдельные согласия, арифметическое занятие,
расчёт подписки по каждому ребёнку и отдельный административный экран тарифов.
Полный продукт ещё не реализован; доступны браузерный клиент и Flutter-клиент с веб-сборкой.

## Запуск

Python 3.12, без сторонних runtime-зависимостей:

```bash
cd /workspace/ai-tutor-kazakhstan
python3 -m backend.application
```

Сервер слушает `127.0.0.1:8081`, клиент находится в `web/`.
Маршрут: настройка со взрослым → регистрация → отдельные согласия → профили →
занятие. Возвращение к родительским данным требует серверного PIN gate.
Используйте взрослые тестовые аккаунты и вымышленные детские профили: контакт
не подтверждается, восстановления доступа и production privacy-инфраструктура ещё не настроена.

База `.local/tutor.sqlite` исключена из Git. Можно задать `PORT` и
`TUTOR_DATABASE_PATH`; для тестов используйте отдельную временную БД.

## Подписка и администрирование

Утверждённая пользователем начальная цена — **10 000 ₸ в месяц за ребёнка**.
Сервер считает цену × число выбранных профилей, независимо от класса.
Один ребёнок 3 класса и ещё двое 1/4 классов — три отдельных места, 30 000 ₸.
Калькулятор не создаёт оплату или paid-доступ: storefront, receipts и entitlement
ещё не подключены. Актуальная цена реальной покупки будет проверяться в магазине.

Создайте отдельного администратора из доверенной локальной консоли:

```bash
python3 -m backend.create_admin --login your-admin-login
```

Пароль и PIN запрашиваются через `getpass`, не передаются аргументами и не
записываются в Git. Обычный родитель не может назначить себе эту роль.
Войдите созданным аккаунтом через родительскую зону, подтвердите PIN и откройте
«Управление тарифом». Можно менять название, месячную цену за ребёнка и лимит
сохранённых профилей семьи. Можно также менять длительность пробного периода.
Изменения сохраняются в БД, имеют ревизию и audit trail;
новые расчёты сразу используют обновлённую цену без перезапуска сервера.
Изменение лимита не удаляет существующие профили. Верхняя граница — пять,
согласно текущему срезу ТЗ. Currency/period фиксированы как KZT/month.

## Пробный доступ

Один бесплатный пробный период на семью, по умолчанию **3 дня (72 часа)**.
Родитель явно запускает его после согласия на обучение; карта и автосписания
не нужны. Все профили семьи используют один и тот же срок. Добавление ребёнка,
переустановка приложения и повторный запрос не продлевают пробу.
В пределах реализованных функций нет дополнительных лимитов занятий.
Без активного доступа новые уроки не запускаются; уже начатое локальное
задание можно закончить. После пробы автоматического перехода на платный тариф нет.

Администратор может настроить длительность 1–30 дней. Уже выданные сроки
сохраняются, новая политика действует только для новых проб. Реальные платёжные
entitlements и противодействие регистрации повторных семей требуют production
проверки контакта; сейчас гарантия однократности действует на учётную запись семьи.

## Проверка

```bash
python3 -m unittest discover -s backend/tests -v
node --check web/app.js
```

Браузерный smoke test требует Playwright и Chromium. Общий runner автоматически создаёт отдельную временную БД,
вымышленные аккаунты и тестового администратора, затем удаляет тестовые данные. Проверенная установка инструментов вне checkout:

```bash
npm install --prefix /workspace/tools/ui-check --cache /workspace/.npm-cache playwright@1.64.0
NODE_PATH=/workspace/tools/ui-check/node_modules python3 -m backend.tests.browser_runner
```

Настройки теста: `CHROMIUM_PATH` (по умолчанию `/usr/bin/chromium`),
`TUTOR_BASE_URL`, `TUTOR_SCREENSHOT`, `TUTOR_EXPECT_TOTAL`.
Предыдущий `python3 -m backend.server` оставлен для совместимости;
новый workflow использует `backend.application` и `/v1`.

## Flutter и учебные материалы

Flutter 3.47.7 / Dart 3.13.5. Из `app/` выполнить `flutter pub get`,
`flutter analyze`, `flutter test`, затем
`flutter build web --base-href /app/ --no-web-resources-cdn`.
Сервер выдаёт сборку по `/app/`; для мобильного клиента адрес API задаётся
через `--dart-define=API_BASE_URL=https://your-host/v1/`.
Android/iOS scaffold создан, сборки и проверки на устройствах пока не выполнены.

В облачной среде используйте PUB_CACHE=/workspace/.pub-cache,
XDG_CONFIG_HOME=/workspace/.config и
ANALYZER_STATE_LOCATION_OVERRIDE=/workspace/.dartServer.

`content/curriculum-399.json` содержит 2014 извлечённых нормативных целей
с источником и контрольной суммой; применимость на текущий учебный год требует
методической проверки. `content/original-math-lessons.json` содержит 32 авторских
черновика для классов 1–4, RU/KK. Они не публикуются автоматически.
Админские экраны A01–A03 поддерживают версии, методическую и языковую проверку,
публикацию и отзыв. Доверенное создание редакционных аккаунтов:
`python3 -m backend.create_admin --login <login> --role <role>`;
роли editor, method_reviewer, language_reviewer, publisher. Пароль/PIN вводятся
через getpass. Автор не может проверять свой урок.

## Данные и прогресс

P08: экспорт JSON и удаление профиля/семьи требуют повторного пароля, не только PIN.
Сервер выполняет локальную очередь, экспорт доступен 24 часа только взрослому.
После удаления семьи токены отзываются сразу; минимальный статус доступен по
случайному receipt, сохраняемому только в памяти клиента. Учебные данные удаляются,
минимальные журналы согласий/удаления остаются отдельно. Production сроки хранения
и backup SLA не утверждены.

Локальный worker: `python3 -m backend.worker --database <path> --drain`.
Снимок: `python3 -m backend.backup --database <path> --output <new-file>`.
При восстановлении сохраняйте соседний файл `<path>.deletion-ledger.sqlite`:
он повторно применяет удаления до допуска запросов. Это не заменяет внешний,
зашифрованный backup storage с retention/reconciliation.

Подсказки записываются сервером. P05 показывает помощь и самостоятельный перенос
по цели и версии; повтор одного примера не объявляется освоением темы.
Взрослая зона закрывается через 2 минуты бездействия или при уходе в фон.
Административные экраны доступны в отдельном браузерном интерфейсе.
